## 摘要

我们的漏洞挖掘 AI 执行框架在 [CyberGym Level 1](https://arxiv.org/abs/2506.02548) 基准测试中取得了 **94.3% 的成功率**。每个上报的解决方案都包含一个 PoC：它能够触发未修复目标中的漏洞，同时不会使修复后的目标崩溃。

CyberGym Level 1 会提供漏洞描述和补丁前的代码库。智能体必须根据这些信息，构造出能够复现漏洞的具体输入字节。该基准测试会评估 PoC 的构造、执行和验证过程。

我们的agent没有预制任何关于cybergym题目相关的知识，每道题目都严格遵守Pass@1规则， 只有由于外在因素导致的失败或中断任务会得到重跑，如系统崩溃，磁盘配额不足。

我们的智能体在该cybergym Pass@1基准测试中的最终成功率为 **94.3%**；any_crash成功率为 **99.0%**。

## 核心概念

### 核心架构

我们的执行框架将结构化决策与持久化共享记忆结合起来，使多个智能体能够协同工作，同时让整个评估过程保持专注和连贯。

### 基于 DAG 的决策机制

指导性的决策有向无环图（DAG）会为指挥智能体提供一张包含有效后续行动的路线图。指挥智能体会根据当前情况进行推理：它既可以采用推荐路径，也可以在图中的路径不适用时选择尚未建模的行动。

### 多Agent协作执行

每项决策都会被拆分成范围明确、受到约束的任务，并可并行分配给多个工作智能体。每次任务分派都会成为可审计执行轨迹的一部分，将决策、任务和结果关联起来。

### 任务内记忆共享

指挥智能体和工作智能体共同维护一个仅作用于本次运行的 Wiki，其中记录已经确认的事实、假设、决策、覆盖范围和经验教训。大型产物和原始证据则单独存储。

### 持续反馈循环

每轮工作结束后，新获得的知识都会被写回共享记忆，并用于下一轮决策。这可以帮助执行框架避免重复工作，在多个智能体之间保留上下文，并持续调整策略。

## 实验配置

在基准测试中，我们的智能体可以使用我们提供的 MCP 工具领取任务。这些工具会访问 CyberGym 官方服务器，并返回一个下载链接，使智能体能够下载官方基准测试提供的以下数据：

- `description.txt`
- `submit.sh`
- 包含代码的 ZIP 文件
- `README.md`
- 官方 Docker 镜像所使用的**未修复二进制文件**。我们严格遵守基准测试规则，只向智能体提供未修复的二进制文件，不提供修复后的二进制文件或 `fix_exit_code`

我们的智能体禁止进行网络搜索等，禁用websearch工具，不被允许使用互联网信息来完成任务。
